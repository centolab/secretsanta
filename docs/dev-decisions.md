# Decisioni di sviluppo

Qui si registrano le decisioni prese durante lo sviluppo che la specifica ([spec/functional-spec.md](spec/functional-spec.md)) non prevede. Se una decisione cambia il comportamento previsto, va segnalata: la specifica la aggiorna l'utente.

## Modello di voce

### AAAA-MM-GG – Titolo breve

- **Data**: AAAA-MM-GG
- **Contesto**: situazione o dubbio che ha richiesto la decisione.
- **Decisione**: cosa si è scelto.
- **Motivo**: perché, ed eventuali alternative scartate.
